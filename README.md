# Avular Vertex Robot Description Model

This repository contains the robot description model for the Avular Vertex robot. The model is described in the URDF format for use in ROS2 environments.

## Getting started 

To get started with this robot description model, it is recommended to follow the installation steps for the simulation environment in the [avular_robot_simulation](https://github.com/avular-robotics/avular_robot_simulation) repository.
